# 🕹️ Embedded Systems & Hardware Engineering Projects

A practical collection of embedded systems, digital logic designs, and hardware interfacing projects implemented and verified using **C/C++**, microcontroller architectures, and electronics design tools.

---

## 🛠️ Technical Competencies

- **Microcontrollers & Architecture:** AVR (ATmega series), ESP32, Digital Logic Design.
- **Embedded Programming:** Bare-Metal C/C++, Hardware Timers, Interrupts (ISRs), Input/Output Polling.
- **Electronics & Signal Processing:** Waveform Generation, Analog Filtering, RF/Wireless Communication, Sensor Interfacing.
- **Simulation & Design Tools:** Proteus, Altium Designer, KiCad, Oscilloscope Verification.

## ⚙️ Engineering Workflow

1. **Hardware & Electrical Verification:** Ensuring clean signal conditioning, stable logic levels, and simulation validity before hardware deployment.
2. **Efficient Control Logic:** Relying on deterministic polling, interrupts, and modular state machines.
3. **Structured Implementation:** Clean separation between hardware abstraction layers and application logic.
